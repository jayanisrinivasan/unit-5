# Unit 5: Find your position — course-page mockup

Static site, no build step.

## Deploy on Vercel
1. Push this folder to a GitHub repo (or drag the folder onto vercel.com/new).
2. Framework preset: **Other**. Build command: none. Output directory: `.`
3. Deploy.

Or from the terminal: `npx vercel --prod` inside this folder.

Answers typed into the exercise boxes are saved in the viewer's own browser (localStorage) and never leave it.
